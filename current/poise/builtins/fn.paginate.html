This is an example implementation of pagination. To tweak the behavior, copy the source code and adjust to your needs:

  • change embed appearance
  • use different emojis for the navigation buttons
  • add more navigation buttons
  • change timeout duration
  • add a page selector dropdown
  • use reactions instead of buttons
  • remove message after navigation timeout
  • …

Note: this is a long-running function. It will only return once the timeout for navigation button interactions has been reached.
