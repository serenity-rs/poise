pub async fn on_error<U, E: Into<Box<dyn Error + Send + Sync>>>(
    error: FrameworkError<'_, U, E>,

Expand description

An error handler that logs errors either via the [tracing] crate or via a Discord message. Set up a logger like tracing subscriber (e.g. tracing_subscriber::fmt::init()) to see the logged errors from this method.

If the user invoked the command wrong (crate::FrameworkError::ArgumentParse), the command help is displayed and the user is directed to the help menu.

Can return an error if sending the Discord error message failed. You can decide for yourself how to handle this, for example:

if let Err(e) = poise::builtins::on_error(error).await {
    tracing::error!("Fatal error while sending error message: {}", e);
}

22async fn on_error(error: poise::FrameworkError<'_, Data, Error>) {
23    // This is our custom error handler
24    // They are many errors that can occur, so we only handle the ones we want to customize
25    // and forward the rest to the default handler
26    match error {
27        poise::FrameworkError::Setup { error, .. } => panic!("Failed to start bot: {:?}", error),
28        poise::FrameworkError::Command { error, ctx, .. } => {
29            println!("Error in command `{}`: {:?}", ctx.command().name, error,);
30        }
31        error => {
32            if let Err(e) = poise::builtins::on_error(error).await {
33                println!("Error while handling error: {}", e)
34            }
35        }
36    }
37}
